# ЛР6. Отопительные приборы

React-интерфейс для гостя и создателя. Лента, плитка и демонстрационные медиа перенесены из ЛР5. С работающим Go-сервисом приложение загружает реальные приборы, по JWT определяет доступные действия и отправляет файлы в хранилище через сервер.

## Запуск в WSL

Распакуй архив в корень `~/labs_rip_frontend` на ветке `lab6-redux-toolkit-auth`. В корне должны оказаться `README.md`, `docs/` и `frontend/`. Команды npm выполняются внутри `frontend/`. Используй Node.js 22.12+ или Node.js 24.

```bash
cd ~/labs_rip_frontend/frontend
npm ci
npm run dev
```

Открой адрес Local из терминала Vite. Для первых двух скриншотов оставь Go-сервис выключенным. Надпись «Демо · без сервера» означает, что гостю показаны локальные данные после неудачного запроса. Сообщение ECONNREFUSED в терминале Vite ожидаемо в этом режиме.

Для остальных скриншотов оставь Vite запущенным. Во втором терминале запусти существующие контейнеры и Go-сервис ЛР4 со своим обычным файлом настроек:

```bash
docker start heating_postgres heating_redis minio_storage heating_adminer
cd ~/labs_rip/awesomeProject
go run ./cmd/awesomeProject
```

Обнови страницу. Используй учётную запись из ЛР4. Для формы добавления можно выбрать файлы из `frontend/public/media/images` и `frontend/public/media/videos`. Небольшое готовое видео — `indirect-boiler.mp4`.

## Страницы и состояние

- **Лента.** Сервер выбирает первый прибор и следующий по ID. После последнего возвращает первый. Создатель может поставить или снять лайк, счётчик берётся из ответа Go.
- **Плитка.** Минимальная мощность передаётся серверу в `min_power`. Поле поиска, применённое значение и сортировка хранятся в Redux. Клиент сортирует по цене или по убыванию ID, так как дата создания в ответе плитки отсутствует. При выходе фильтр сбрасывается. Кнопка удаления доступна у своей карточки по `is_creator`.
- **Вход.** Компонент вызывает Axios для `POST /api/users/auth` или `POST /api/users/logout` и отдельно отправляет Redux action. JWT хранится в localStorage. После F5 интерфейс открывается для гостя и посылает гостевые запросы. Сохранённый JWT остаётся доступен для показа в Postman. При явном выходе сервер отзывает токен, клиент очищает его и сбрасывает состояние.
- **Добавление.** При открытии загружается существующий черновик. Для нового укажи название, мощность, цену, фото и видео. Выбранное фото видно до отправки. «Сохранить черновик» отправляет multipart-форму, «Опубликовать» выполняет отдельный PUT. После публикации открывается плитка. Черновик можно удалить.
- **Ожидание.** Пока выполняется запрос, индикатор загрузки закрывает интерфейс, мышь и клавиатура не активируют кнопки. Ошибки записи отображаются на экране. Демоданные используются только для чтения в гостевом режиме при недоступности сервиса.

## Кодогенерация и проверка

В архиве уже есть сгенерированный Axios-клиент. Команды для повторной генерации и проверки:

```bash
cd ~/labs_rip_frontend/frontend
npm run api:generate
npm run lint
npm run build
```

Исходная спецификация в `frontend/openapi/swagger.json` взята из `awesomeProject/docs/swagger.json`, ветка `lab4-auth-swagger`, коммит `43a80c7` репозитория Creature547/labs_rip. Скрипт генерации выбирает методы приборов, задаёт им предметные имена и отмечает поля, которые Go-сериализатор возвращает всегда. Серверный код в этот архив не входит.

В `frontend/vite.config.ts` определены два маршрута прокси. Запросы `/api` идут на порт 8080, а `/s3` — на порт 9000 с удалением префикса. В исходном JSON сервера можно увидеть адрес хранилища, а в Network браузера — адрес прокси, имя бакета и имя файла.

Диаграмма прецедентов в формате SVG для РПЗ — `docs/react-use-cases.svg`.
