# Лабораторная работа 5

Базовое одностраничное приложение для просмотра отопительного оборудования.
Проект выполнен на React, TypeScript, Vite и React-Bootstrap. Данные карточек
хранятся только в mock-коллекции в `src/App.tsx`; запросы к серверу, Redux и
React Context не используются.

## Запуск

```bash
npm install
npm run dev
```

После запуска приложение доступно по адресу, который выведет Vite (обычно
`http://localhost:5173`).

## Страницы

### Лента

Доступна гостю. На странице показывается одна карточка оборудования с видео,
изображением-заставкой, названием, мощностью, стоимостью, описанием и числом
лайков из mock-данных. Кнопка со стрелкой переключает следующую карточку.

Если видео отсутствует или не загружается, вместо него отображается
изображение. Если отсутствует и изображение, используется локальный файл
`src/assets/default-video.svg`.

### Плитка

Доступна гостю. Карточки выводятся в сетке по две на строку. На каждой
карточке отображаются изображение, название, мощность, стоимость и число
лайков из mock-данных.

Поле «Мин. мощность, кВт» фильтрует карточки по минимальной мощности после
нажатия кнопки «Найти». Выпадающий список задаёт сортировку: сначала новые или
по возрастанию цены.

Если изображение отсутствует или не загружается, используется локальный файл
`src/assets/default-equipment.png`.

## Навигация

В нижней панели есть четыре пункта: «Лента», «Добавление», «Плитка», «Вход».
В этой лабораторной доступны только «Лента» и «Плитка». Пункты «Добавление» и
«Вход» отображаются, но отключены.

## Медиафайлы

Локальные медиафайлы карточек находятся в папках:

```text
public/media/images
public/media/videos
```
