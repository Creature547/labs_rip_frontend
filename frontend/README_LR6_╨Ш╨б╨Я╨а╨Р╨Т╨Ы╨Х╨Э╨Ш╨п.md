# ЛР6 — исправления по замечаниям преподавателя

## 1. Страница «Добавление»

Файл: `src/pages/AddEquipment.tsx`.

Первый экран соответствует сценарию демонстрации ЛР6: название отопительного прибора, **отдельные очевидные кнопки «Выбрать изображение» и «Выбрать видео»**, предпросмотр изображения и кнопка **«Далее»**. Выбранные файлы и название сохраняются при переходе между шагами.

На втором экране запрашиваются описание, мощность и стоимость. Они нужны серверному методу `POST /api/heating-equipment`, поэтому удалять эти поля полностью было бы ошибкой. Кнопка **«Создать черновик»** выполняет запрос к Go API. Затем пользователь видит черновик с действиями **«Опубликовать»** и **«Удалить черновик»**, как и раньше.

Стили формы: `src/App.css`, блок в конце файла `/* ЛР6: экран добавления по шагам ... */`.

## 2. Авторизация перенесена из App

Файл: `src/pages/Login.tsx`.

Здесь теперь находятся `handleLogin`, `handleLogout`, вызовы `authApi.post('/auth', ...)` и `authApi.post('/logout', ...)`, работа с JWT (Local Storage) и отправка Redux-действий `signedIn/signedOut`.

`src/App.tsx` больше **не импортирует и не вызывает authApi**: он только управляет показом страниц и передаёт колбэки переходов. Сама общая конфигурация Axios (`authApi = axios.create(...)`) остаётся в `src/api/client.ts`, как и подобает конфигурации API-клиента. Используется этот клиент непосредственно в странице `Login.tsx`.

## Как запустить

В WSL (с запущенными Docker и Go-сервером):

```bash
cd ~/labs_rip_frontend/frontend
npm ci
npm run build
npm run dev
```

Открыть `http://localhost:5173` и проверить вход, затем вкладку «Добавление».

## Что проверено

Статическая проверка всех TypeScript/TSX-файлов: синтаксис корректен, локальные импорты существуют, в `App.tsx` отсутствует `authApi`, а вызовы авторизации находятся в `pages/Login.tsx`.

Автоматическую сборку `npm run build` и работу с Go API нужно проверить локально: в среде подготовки архива не удалось загрузить необходимые npm-зависимости из реестра. Данные PostgreSQL, Redis, MinIO и backend не изменялись.
